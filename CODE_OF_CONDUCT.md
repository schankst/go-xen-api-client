# Code of Conduct

This community values respectful, technical collaboration.

## Expected Behavior

- **Be constructive:** Code reviews, issues, and discussions focus on the work, not the person. Disagree on the implementation, not on merit.
- **Be concise:** Respect others' time. Issues and PRs should be clear and focused.
- **Be honest:** If something doesn't work, say so. If you don't know, say that too.

## Unacceptable Behavior

- Harassment, discrimination, or bad-faith attacks on contributors
- Dismissing technical concerns without engagement
- Off-topic derailment of issues or PRs

Violations can be reported privately to the maintainers. We take all reports seriously and will respond promptly.
